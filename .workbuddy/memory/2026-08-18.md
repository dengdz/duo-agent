## 第二部分（用户带 API key 跑测试后发现 bug）

- 用户运行 `mvn test -Dtest=DeepSeekAdapterTest`（已设 `DEEPSEEK_API_KEY`）发现：`工具调用往返测试` 流程正常（tool/call、tool/result 事件都在），但 `TodoWriteTool` 实际**记录了 0 个任务**。
- 根因：`ReactLoopAgent.parseJsonArgs()` 用扁平正则解析，把 `{"todos":[...]}` 数组整个当字符串塞进 map；`TodoWriteTool.execute` 里 `(List<Map<String,String>>) args.get("todos")` 强转 String→List 抛 `ClassCastException`，被 ToolRegistryImpl 兜底成"错误结果"，所以测试假绿（只断言了事件存在，没断言任务数）。
- 修复：新增零依赖 `dev.dsh.util.JsonParser`（递归下降解析嵌套 JSON）；`parseJsonArgs` 改用它；`TodoWriteTool` 改为消费 `List<Map<String,Object>>`。
- 新增 `JsonParserTest`、`TodoWriteToolTest` 锁住回归；`工具调用往返测试` 补充 `assertFalse(todos.isEmpty())`。
- 测试全绿：`mvn test` → 76 tests / 0 failures / 3 skipped（本机无 API key 跳过真实调用）。
- 提交：
  - `9cc9571 fix(tools): 修复工具参数解析——嵌套 JSON 被当成字符串导致工具执行失败`
  - docs: HANDOFF.md 记录工具参数解析修复
